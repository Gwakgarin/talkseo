# TALKSEO (톡서)

독서 과정을 기록하고 시각화하며, 독서 경험을 함께 나누는 커뮤니티를 통해
꾸준한 습관과 성취감을 만들어주는 서비스

## 목표

- 독서 타이머로 실시간 독서 시간 기록
- 도서별 독서 기록 및 감상평 작성
- 커뮤니티를 통한 독서 경험 공유
- 읽은 기록 시각화 및 통계 제공

## DB 구조

### 주요 테이블

- `USERS` — 사용자 정보
- `BOOK` / `BOOK_AUTHOR` / `BOOK_PUBLISHER` — 도서 정보
- `USER_BOOK` — 사용자별 독서 상태 (읽기 전 / 읽는 중 / 중단 / 완료 등)
- `READING_SESSION` — 독서 세션 기록 (시작/종료 페이지, 독서 시간)
- `REVIEW` / `REVIEW_LIKE` — 감상평 및 좋아요
- `COMMUNITY_POST` / `POST_COMMENT` / `POST_IMAGE` / `POST_LIKE` — 커뮤니티 글/댓글/이미지/좋아요
- `SEARCH_LOG` — 검색 로그
- `REPORT` — 신고 (비매너/욕설/성희롱/기타)

### 상태값 규칙 (공통)

- `status`: 0-보임, 1-안보임, 2-삭제 (테이블별로 상이하니 각 테이블 comment 참고)
- `USER_BOOK.status`: 0-읽기 전, 1-읽는 중, 2-중단, 3-삭제/취소, 4-완료

전체 SQL 쿼리는 `/docs` 또는 별도 파일 참고 (`Talkseo_쿼리.pdf` 원본 기획 문서 기반)
